# Round and Phases

The game is played in [[phase]]s which are tracked on the [[phase board]].
The phase board has four tracks, one per [[phase]]. Each track has a colored border indicating their phase.
1. The [[Event Phase]] has a purple border. This is the first phase. Put the [[phase marker]] above track.
2. The [[Discovery Phase]] has a blue border.
3. The [[Expansion Phase]] has a yellow border.
4. The [[Control Phase]] has a red border.
On the Event Phase track lie the [[public]] [[event card]]s. On the other tracks lie the public [[action card]]s of that phase.

## Taking turns

In [[natural order]], each player either activates one card of the current phase or [[pass]]es.

When it is not your turn, choose **Force pass** to automatically pass every remaining turn you have in the current phase. This ends automatically when the next phase starts. You must still answer any pending reactions or other player decisions.

During the Event Phase, a player with no playable event cards automatically passes their turn. This cannot be switched off and does not skip pending votes, reactions, or other decisions.

Activating [[event card]]s [[taps]] that card. Activating [[action card]]s requires tapping a [[character]] or [[activation card]] of that type.

The next phase starts when every player passes in a row, or when no card of the current phase can be activated. 

When the last phase ends (the control phase), check the victory condition of the [[Chapter]] (the game starts in the [[New Dawn]] chapter). If nobody wins, move the phase marker back to the event phase and play another round.
