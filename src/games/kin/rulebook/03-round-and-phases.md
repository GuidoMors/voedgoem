# Round and Phases

The game is played in [[phase]]s which are tracked on the [[phase board]].
The phase board has four tracks, one per [[phase]]. Each track has a colored border indicating their phase.
1. The [[Event Phase]] has a purple border. This is the first phase. Put the [[phase marker]] above track.
2. The [[Discovery Phase]] has a blue border.
3. The [[Expansion Phase]] has a yellow border.
4. The [[Control Phase]] has a red border.
On the Event Phase track lie the [[public]] [[event card]]s. On the other tracks lie the public [[action card]]s of that phase.

## Taking turns

In [[natural order]], each player either activates one card of the current phase or [[pass]]es.
Activating event cards costs nothing. Activating action cards may have a cost, and always require tapping a character or action card of that type.

A phase ends when every player passes in a row, or when no card of the current phase can be activated. When the phase ends, move the [[phase marker]] to the next track. When the last phase ends (the control phase), check the victory condition of this [[Chapter]]. If nobody wins, move the phase marker back to the [[event]] [[phase]].
